# Справочник команд suai-report

Всё ниже проверено на suai-report v2.7.1. Исходник пакета —
`~/texmf/tex/latex/suai-report/suai-report.sty` (`kpsewhich suai-report.sty`);
если поведение расходится с этим файлом, прав исходник.

## Содержание

- Документ и титул: `\suaisetup`
- Структура: введение, разделы, заключение, приложения
- Списки
- Таблицы
- Рисунки
- Формулы
- Листинги
- Ссылки
- Источники
- Настройка под методичку
- Заготовка `main.tex` без команды `suai`
- Команда `suai`
- Ошибки сборки

## Документ и титул

```latex
\documentclass[a4paper,14pt]{extarticle}
\usepackage{suai-report}

\suaisetup{
  department   = 41,
  teacher-post = доцент, канд. техн. наук,
  teacher      = И. И. Иванов,
  type         = Отчет о лабораторной работе,
  number       = 1,
  title        = Название работы,
  course       = Название дисциплины,
  group        = 4414,
  student      = И. И. Студентов,
  date         = today,
}

\begin{document}
\maketitle
\suaitoc
…
\end{document}
```

- `type` печатается прописными сам. Варианты: «Отчет о лабораторной
  работе», «Отчет о практической работе», «Курсовая работа», «Пояснительная
  записка к курсовому проекту», «Доклад».
- `number` пустой (`number = ,`) — без «№».
- `title` — как в методичке, обычным регистром (прописными сделается сам).
- `date = today` — дата сборки ДД.ММ.ГГГГ; `date = 12.09.2026` — своя;
  без `date` или пусто — пустые линии, чтобы вписать от руки.
- Несколько студентов: `student = А. А. Иванов, Б. Б. Петров` — по строке
  на каждого.
- Запятые в значениях не надо брать в скобки: `teacher-post = доцент,
  канд. техн. наук` работает.
- Ещё ключи: `course-label` (по умолчанию «по курсу:», у курсовых часто
  «по дисциплине:»), `year`, `city`.
- Символы `% # & _` в значениях — с обратной косой: `\%`, `\_`. Значение
  со знаком `=` берётся в скобки: `title = {Расчёт y = kx}`.
  `suai new --title "…"` экранирует и ставит скобки сам.

`\maketitle` — титул (считается страницей 1, номер не печатается).
`\suaitoc` — «СОДЕРЖАНИЕ» с новой страницы.

## Структура

```latex
\suaiintro                    % ВВЕДЕНИЕ, с новой страницы, в содержании
\section{Ход работы}          % 1 Ход работы, с новой страницы
\subsection{Установка}        % 1.1 Установка
\subsubsection{…}             % 1.1.1
\suaisection{Вариант задания} % любой элемент без номера, прописными
\suaiconclusion               % ЗАКЛЮЧЕНИЕ
```

Каждый `\section` и `\suaisection` начинается с новой страницы — это по
ГОСТу, `\clearpage` перед ними не нужен.

### Приложения

```latex
\suaiapp{Исходный код программы}              % (обязательное)
\suaiapp[справочное]{Результаты измерений}
```

Буквы А, Б, В… (без Ё, З, Й, О, Ч, Ъ, Ы, Ь). Рисунки, таблицы, формулы и
листинги внутри нумеруются А.1, А.2. Приложения идут после
`\suaisources`. В тексте ссылаются так: `приведен в приложении~А`.

## Списки

```latex
\suaitasks
установить Obsidian и создать хранилище
настроить синхронизацию

\suailist
панель файлов слева
редактор заметок в центре

\suaienum            % а) б) в)
\suainum             % 1) 2) 3)
```

- `\suaitasks` печатает «Для достижения поставленной цели необходимо решить
  следующие задачи:» и список а), б). Своя фраза: `\suaitasks[Задачи
  работы:]`; без фразы — `\suaitasks[]`.
- Пунктуация ставится сама: `;` после пунктов, `.` после последнего. Свои
  `; . ,` в конце пункта заменяются, `? ! :` остаются. Точка сокращения
  в конце пункта (`и т. д.`, `и т. п.`, `и др.`, `и пр.`, `г.`, `гг.`,
  `вв.`, `руб.`, `коп.`, `тыс.`, `шт.`, `экз.`, `стр.`) сохраняется:
  «и т. д.;». Со звёздочкой
  (`\suailist*`, `\suaienum*`, `\suainum*`, `\suaitasks*`) пунктуация не
  трогается — для пунктов-предложений с заглавной буквы и точкой.
- Перед списком обычно стоит вводная фраза с двоеточием: «Основные элементы
  интерфейса:». Её можно писать прямо на строке перед командой, без пустой
  строки.
- Вложенных списков блочные команды не делают. Если нужен второй уровень —
  обычный `\begin{enumerate}`/`\begin{itemize}` (оформление уровней пакет
  уже настроил), но сначала подумай, не проще ли таблица.

## Таблицы

```latex
Способы синхронизации сравниваются в~\tabref{sync}.

\suaitable[sync]{Сравнение способов синхронизации}
Способ          | Стоимость    | Шифрование
Obsidian Sync   | 4 \$ в месяц | да
Яндекс Диск     | бесплатно    | нет
```

- Первая строка — шапка (по центру, без полужирного), первый столбец — влево,
  остальные — по центру. Ширины столбцов подбираются по тексту сами;
  `\allowbreak`, `p{…}`, ручные ширины не нужны.
- Метка `[sync]` даёт `tab:sync`. Без метки на таблицу не сослаться, а по
  ГОСТу ссылка нужна — ставь метку всегда.
- Единицы измерения — в название через запятую: `{Поступление ТМЦ, руб.}`.
- Пустая ячейка — пробел между `|`: `Итого |  | 184 000,00`.
- Длинная таблица сама переходит на следующую страницу с «Продолжение
  таблицы 1» и повтором шапки.
- В ячейках работает обычный LaTeX: `$x^2$`, `\texttt{…}`, `\%`, `\$`, `\&`,
  `\_`, `\#`. Символ «|» в тексте ячейки — `\textbar{}`; `\|` — это
  математическая ‖, вне формулы даёт «Missing $».
- Формула в ячейке — как в тексте, с пробелами тоже: `$a + b$`,
  `\( a + b \)`. Черта внутри формулы ячейку не делит:
  `$|x|$ | модуль числа` — две ячейки.
- Комментарий `%` в строке таблицы (и любого блока) относится только к
  этой строке; строка из одного комментария пропускается. `%` внутри
  скобок (`\url{…a%20b}`) остаётся текстом.
- Таблица, набранная руками (`tabular`, `longtable`), получает тот же
  межстрочный интервал, что и `\suaitable`, — как в тексте.
- Объединённых ячеек нет. Если они правда нужны — `xltabular` руками, с
  `\caption` и `\label{tab:…}` (см. оформление в демо пакета), но обычно
  таблицу лучше перестроить.
- Выравнивание пробелами в исходнике — только для читаемости, на результат
  не влияет.

## Рисунки

```latex
Окно программы показано на~\figref{scheme}.

\suaiimg{scheme}{Главное окно Obsidian}
\suaiimg[0.5\textwidth]{diagram}{Схема сети}
\suaiimg{scheme}{То же окно после настройки}[scheme-after]
```

- Файл ищется в `images/` и рядом с `main.tex`; расширение писать не
  нужно (`png`, `jpg`, `pdf`).
- Ширина по умолчанию `0.8\textwidth`; рисунок шире полосы урезается до
  полосы, выше 0,75 страницы — уменьшается. Узкий вертикальный скриншот
  (окно телефона, меню) лучше ставить `[0.4\textwidth]`–`[0.5\textwidth]`.
- Метка — `fig:имя-файла` (`scheme` → `fig:scheme`). Четвёртый
  необязательный аргумент — своя метка; нужен, если один файл вставлен
  дважды.
- Подпись — с прописной буквы, без точки в конце, по содержанию рисунка.
- Рисунок встаёт ровно там, где написан (`[H]`), поэтому ставь его после
  абзаца со ссылкой на него.
- Два скриншота рядом в одном рисунке командой не делаются; лучше
  склеить картинку заранее или дать два рисунка.
- График по данным (замеры, CSV) — скриптом matplotlib в
  `images/имя.png` (dpi 200, подписи осей по-русски, без заголовка над
  графиком — его роль играет подпись), затем `\suaiimg`. Скрипт положи
  рядом (`plot.py`), чтобы график можно было перестроить. pgfplots и
  `\begin{figure}` руками не нужны.

## Формулы

```latex
Объём хранилища оценивается по~\formref{size}:
\suaieq[size]{V = N \cdot \bar{s}}
V | объём хранилища, КБ
N | число заметок
\bar{s} | средний размер заметки, КБ

Для 300 заметок по 4 КБ получаем 1,2 МБ.
```

- Метка `[size]` → `eq:size`, номер (1) справа.
- Строки `обозначение | смысл` дают «где V — объём хранилища, КБ;» с
  выравниванием. `$` вокруг обозначения добавляется сам. Без строк —
  формула без пояснений, но пустая строка после неё всё равно нужна.
- Формулы в строке — обычные `$…$`. Многострочная выкладка — `\begin{align}`
  руками (`\label{eq:…}`, чтобы работал `\formref`).
- Нумерация по разделам (1.1) — `\numberwithin{equation}{section}` в преамбуле.

## Листинги

Код в тексте — строки **с отступом** под командой:

```latex
Скрипт приведен в~\lstref{backup}.

\suaicode[bash, backup]{Резервное копирование хранилища}
    #!/bin/bash
    # архив с датой в имени
    tar -czf "vault-$(date +%F).tar.gz" ~/Obsidian/Vault

    echo "Готово"

Дальше обычный текст.
```

- Квадратные скобки: первое значение без `=` — язык, второе — метка
  (`backup` → `lst:backup`). Значения с `=` — ключи listings
  (`firstnumber=10`, `language={[Sharp]C}`, `label=lst:имя`).
- Языки — из listings и добавленные пакетом (JavaScript, TypeScript,
  Kotlin, Rust, JSON, YAML, Dockerfile); регистр не важен, есть короткие
  имена (`cpp`, `cs`, `js`, `ts`, `py`, `kt`, `rs`, `yml`, `docker`),
  `C#` пишется как есть: `\suaicode[C#, form]{…}`. Список — в SKILL.md.
- Без языка (вывод консоли, язык вне списка):
  `\suaicode[label=lst:out]{Вывод программы}`.
  Позиционно метку без языка не передать — `[, out]` не работает.
- Неизвестный язык сборку не останавливает: код набирается без
  подсветки, в логе остаётся `Язык листинга '…' неизвестен`,
  `check_report.py` покажет это предупреждением.
- Отступ любой (≥ 1 пробела или табуляция), общий срезается. Пустые строки
  внутри кода сохраняются. Код кончается на первой непустой строке без
  отступа — эта строка уже обычный текст.
- Внутри кода ничего не экранируется: `%`, `#`, `\`, `{}`, `$`, кириллица —
  как есть.
- На строке с `\suaicode…{Подпись}` после подписи ничего нет (иначе
  ошибка «После подписи \suaicode на той же строке ничего не пишется»).
- Подпись — LaTeX: `Файл dags/clickhouse\_upload.py`.
- Длинные строки переносятся сами со значком ↪.
- Листинг, не поместившийся на странице, продолжается на следующей под
  строкой «Продолжение листинга N», как таблица. Подпись внизу страницы
  без кода не остаётся: листинг уходит на следующую страницу целиком.
  Руками (`\clearpage`, `\newpage`) листинги двигать не нужно.

Код из файла — вторая пара скобок на той же строке:

```latex
\suaicode[Python]{sort.py}{Сортировка пузырьком}          % метка lst:sort
\suaicode[Python, main]{src/app/main.py}{Точка входа}     % метка lst:main
\suaicode[C++]{lab.cpp}{Программа}[lst:program]           % своя метка
```

Файл ищется от папки отчёта и в `code/`. Для длинных программ это лучше,
чем копировать код в текст: исходник один. Целые программы на несколько
страниц обычно уносят в приложение.

Цветные листинги — `\lstset{style=gostcolor}` в преамбуле (по ГОСТу
нежелательно; только если просят). Окружение `\begin{code}` из отчётов
до v2.5 не используй, даже если оно есть в соседнем отчёте: код
пишется только через `\suaicode`.

## Ссылки

| Команда | Печатает | Пример в тексте |
| --- | --- | --- |
| `\figref{scheme}` | рисунке 1 | `показано на~\figref{scheme}` |
| `\tabref{sync}` | таблице 1 | `приведены в~\tabref{sync}` |
| `\lstref{backup}` | листинге 1 | `приведен в~\lstref{backup}` |
| `\formref{size}` | формуле (1) | `рассчитывается по~\formref{size}` |

Префикс (`fig:`, `tab:`…) писать не нужно. Падеж у команд один —
предложный. Для остальных форм — `\ref` с полной меткой:

```latex
(рисунок~\ref{fig:ris01})
на рисунках~\ref{fig:note-03}--\ref{fig:note-13}
(рисунки~\ref{fig:ris13}, \ref{fig:ris14})
(\tabref{tmc}, рисунок~\ref{fig:ris17})
```

## Источники

```latex
\suaisources
Методические указания к выполнению лабораторной работы «…» по дисциплине «…». СПб.: ГУАП, 2026.
Obsidian Help. URL: https://help.obsidian.md (дата обращения: 12.09.2026).
Фаулер М. Архитектура корпоративных программных приложений. М.: Вильямс, 2015. 544 с.
```

По источнику на строку, нумерация 1., 2. сама. URL переносится сам.
Ссылка в тексте — `[1]` руками. Через biblatex — в преамбуле:

```latex
\usepackage[backend=biber,style=gost-numeric,language=auto,
            autolang=other,sorting=none]{biblatex}
\addbibresource{sources.bib}
```

и `\suaisources` без строк под ним, в тексте `\cite{key}`.

## Настройка под методичку

В преамбуле, после `\usepackage{suai-report}`, и только если методичка или
преподаватель требуют:

| Требование | Строка |
| --- | --- |
| Правое поле 10 мм | `\geometry{right=10mm}` |
| Интервал «1,5» как в Word | `\setstretch{1.42}` |
| Одинарный интервал в таблицах | `\renewcommand{\suaitablestretch}{1}` |
| Формулы по разделам (1.1) | `\numberwithin{equation}{section}` |
| Заголовки не полужирные | `\renewcommand{\suaiheadfont}{\normalfont\fontsize{14}{17}\selectfont}` |
| Цветные листинги | `\lstset{style=gostcolor}` |
| Ключевые слова полужирным | `\lstset{keywordstyle=\bfseries}` |
| Без строки «Продолжение листинга N» | `\renewcommand{\suailistingcontinued}{}` |
| Короткое тире в подписях | `\captionsetup{labelsep=endash}` |
| Без разрывов внутри слов `_ / .` | `\XeTeXinterchartokenstate=0` |

Свои короткие макросы тоже в преамбуле, например `\newcommand{\f}[1]{\texttt{#1}}`
для имён функций Excel.

## Заготовка `main.tex` без команды `suai`

Если `suai` не установлена, но пакет есть (`kpsewhich suai-report.sty`
что-то печатает), создай `images/` и `main.tex` из шаблона в начале этого
файла. Сборка тогда:

```bash
latexmk -xelatex -outdir=build -interaction=nonstopmode -halt-on-error main.tex
cp build/main.pdf "$(basename "$(dirname "$PWD")")-$(basename "$PWD").pdf"
```

## Команда `suai`

| Команда | Что делает |
| --- | --- |
| `suai new DIR [--title T] [--no-open]` | новый отчёт; титул — из свежего соседнего |
| `suai next [--title T] [--no-open]` | из папки `lab-4` создать `../lab-5` с тем же титулом |
| `suai build [DIR]` | собрать PDF (`Предмет/lab-3` → `Предмет-lab-3.pdf`), служебное в `build/` |
| `suai open [DIR]` | собрать и открыть PDF |
| `suai watch [DIR]` | пересобирать при сохранении (не запускай в фоне без нужды) |
| `suai clean [DIR]` | удалить `build/` и PDF |
| `suai update` | обновить `.vscode/` отчёта |

## Ошибки сборки

Сборка идёт с `-halt-on-error`: первая ошибка останавливает всё. Строка
`./main.tex:N: …` — где искать. Ошибку внутри блока (`\suaitable`,
`\suailist`…) TeX показывает строкой, где блок кончился (пустой строкой
после него), — сама ошибка в одной из строк блока; `check_report.py`
называет такой блок.

| Сообщение | Причина |
| --- | --- |
| `File ended while scanning use of \__suai_line:w`, `Couldn't load requested language`, «Missing $» на `$a + b$` в ячейке | пакет старше v2.7 (`kpsewhich suai-report.sty`, первая строка лога) — обновить: `cd suai-report && git pull && make install` |
| Предупреждение `Язык листинга '…' неизвестен` | не ошибка: код набран без подсветки; исправь имя языка или убери его; Lua — только с диалектом `{[5.3]Lua}` |
| `Под \suaicode нет строк с отступом` | код без отступа, или нужна форма из файла `{файл}{Подпись}` |
| `После подписи \suaicode на той же строке ничего не пишется` | текст после `{Подписи}` |
| `File 'x' not found` (graphicx) | нет файла в `images/`; проверь имя и регистр |
| `Missing $ inserted` | `_` или `^` в тексте или ячейке без `$` / `\_`; в таблице — ещё `\|` вне формулы |
| `Misplaced alignment tab character &` | `&` в тексте или ячейке → `\&` |
| `Undefined control sequence` | опечатка в команде или `\` в тексте (путь Windows → `\textbackslash{}` или `\texttt{…}` с `/`) |
| `Extra }, or forgotten $` / `Runaway argument` | несбалансированные скобки, часто `%` без `\` обрезал строку |
| Предупреждение `Шрифт 'Times New Roman' не найден` | не ошибка: подставлен TeX Gyre Termes; сказать пользователю, что нужен `ttf-mscorefonts-installer` |
| `Reference 'fig:x' undefined` | опечатка в метке или рисунок не вставлен |
| `Label 'fig:x' multiply defined` | одна картинка дважды без своей метки |
